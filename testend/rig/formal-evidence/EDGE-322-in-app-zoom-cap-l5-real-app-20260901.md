# EDGE-322 应内缩放到顶：L5 真实 App 可发现性证据

## User goal

普通用户目标是：把界面文字和控件调到自己舒服的大小，在当前屏幕下知道什么时候已经不能再放大，
并能恢复默认。用户不需要知道 `maxFactor` 或窗口设计最小尺寸。

## Real App path

真实 session=`/private/tmp/anselm-rig-formal-20260831-11/sessions/20260901-214830`。从左下角齿轮进入 `Settings`，左侧
选择 `General`，页面清楚显示 `UI zoom` 及说明 `Scales the whole UI, synced with ⌘+ / ⌘− / ⌘0`。
档位直接以 `0.8×`、`0.9×`、`1.0×`、`1.1×`、`1.25×`、`1.5×` 呈现；用户点击 `1.1×` 后可以直观看到
整页放大，当前屏幕不适合的 `1.25×` 和 `1.5×` 呈灰置状态。点击 `1.0×` 即可恢复默认。

## Judgment

设置入口、分类、名称、说明、档位和恢复动作均可见，用户无需内部术语或隐藏命令即可完成调整；灰置
档位清楚表达“当前屏幕不可容纳”，而不是让用户点击后无反馈。L5=`G1`。

本格只判入口、说明、边界反馈和恢复路径的可发现性；布局完整性和逐帧稳定性见
`testend/rig/formal-evidence/EDGE-322-in-app-zoom-cap-l4-real-app-20260901.md`。
