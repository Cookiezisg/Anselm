## 盲走路径

不打开项目文档、不预先调用 API，Computer Use 在真实 App 中完成：

1. 从 onboarding 创建 workspace，进入 Chat，通过可见附件入口打开 macOS 文件选择器并附加 WAV。
2. 以自然语言请求登记具名音色；确认层清楚说明选中的危险工具和参数，用户能判断是否允许。
3. 登记两个音色后进入 Settings → Models & keys，在 `Cloned voices` 区域看到两条具名音色和“两个槽位已占用”的补救文案。
4. 再次从 Chat 请求第三个具名音色；失败卡直白说明库存已满，并指出删除音色才能腾出位置，不要求用户理解 API 错误码。
5. 在设置页 hover 音色行出现 Delete，确认层使用对象名和明确的不可退款说明；删除后空态告诉用户如何从音频附件再次登记，并显示真实剩余槽位。

附件入口、自然语言目标、危险确认、库存补救文案、设置分区和删除后的下一步共同形成闭环；没有依赖隐藏 URL、内部 ID 或额外文档。
