# Code of conduct

Anselm is a small open-source project. Everyone who takes part in it, in issues, pull requests,
discussions or anywhere else the project is represented, is expected to:

- Be direct and be kind. Criticize the work, not the person.
- Assume good faith, and ask before assuming intent.
- Keep the conversation on the project. No harassment, no discrimination, no personal attacks,
  no publishing of other people's private information.
- Respect that maintainers decide what gets merged, and that a "no" is not an invitation to
  relitigate it.

If someone is making the project a worse place to be, tell a maintainer privately at
sunweilin.cn@gmail.com. Reports are handled confidentially. Depending on what happened, the
response ranges from a private note to removal from the project's spaces.
