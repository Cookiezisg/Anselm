# WRK-088 · 验收法典(CODEX)——裁决只引法条与测量值

> WRK-087 §4.1 的交付物。**每个格子的裁决必须援引本典法条 ID 或测量值**;援引不了的那一刻
> 就是该立新法的那一刻——先立法(按 §末立法协议)、再判。法典**只收紧、不放松**;
> 已有裁决不因新法回溯翻案,但同类面自新法起按新法审。
>
> 来源分三层,冲突时上层胜:**仓内已成文军规**(design-system.md / CLAUDE.md——它们是拍过板的,
> 本典只引用不复制数值语义;数值这里抄录仅为judge现场免翻,漂移以原文为准)>
> **行业标准**(WCAG 2.x / RAIL / Doherty / HIG / Nielsen)> **本典自立法**(campaign 中现场立的)。
> 对标档次:Linear / Things / Craft 级桌面手感(用户 P6/P7 拍板语境)。

## A · 时延与反馈

| ID | 法条 | 判定 / 阈值 | 来源 |
|---|---|---|---|
| A1 | 任何用户输入的**可见**反应 ≤100ms;做不到即必须有即时状态指示 | `measure latency`(动作帧→首反馈帧) | RAIL response |
| A2 | 骨架双闸:指示器亮出前延迟 160ms(亚阈值加载**永不**显骨架);真亮出后最短停留 200ms | 录屏逐帧:骨架可见时长 ∉ (0,200ms) | AnMotion.loaderDelay/loaderHold(仓内已立法) |
| A3 | 旧值顶替上限 400ms——超过必须转真实加载态(再顶像「点了没反应」);有旧值**绝不**渲骨架 | 录屏:骨架出现于有旧值面 = 违 | AnMotion.staleHold · Doherty 阈 |
| A4 | >1s 的操作必有进度/状态文案;>10s 必可取消或已后台化 | 录屏 + 目视 | RAIL / Nielsen visibility |
| A5 | 流式期间 UI 不冻结:composer 可打字、transcript 可滚动,交互反馈仍守 A1 | 流式中录屏 + `measure latency` | 仓内丝滑军规 · 终点验收⑤先例 |

## 立法协议(现场立法怎么立)

1. **触发**:一次裁决援引不了任何法条与测量值,或用户/judge 提出新的不适感。
2. **三要素**:新法 = 域内顺延 ID + **可执行判定**(能测量就写 measure 子命令与阈值)+ 来源
   (触发它的格子/事件/原话)。追加进本典对应域,`git` 即时间戳。
3. **只收紧**:改法只允许更严;放松 = 用户拍板事项(记 WRK-087 §6 代拍台账)。
4. **回灌**:新法立即横扫既有同类面(WRK-087 N4 同类横扫),扫出的格子按新法重判。
